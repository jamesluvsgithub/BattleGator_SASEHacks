# BattleGator

Hello!! This is the source code for BattleGator's submission to SASE's first hackathon ever, SASEHacks! BattleGator is a Battleship game - with a fun twist! Instead of ships, the players interact with UF-gator themed sprites, knocking their opponent's gators into the water as they take turns guessing.
